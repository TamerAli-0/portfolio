## 🎨 About

A sleek, modern portfolio website showcasing my projects and skills. Built with vanilla HTML, CSS, and JavaScript featuring stunning animations, interactive particle effects, and a fully responsive design with dark theme aesthetics.

> **No frameworks. No build tools. Pure vanilla web technologies.**

## 🚀 Quick Start

### View Live

Visit the live demo: **[tamerali-0.github.io/portfolio](https://tamerali-0.github.io/portfolio/)**

### Run Locally

```bash
# Clone the repository
git clone https://github.com/TamerAli-0/portfolio.git

# Navigate to directory
cd portfolio

# Open in browser
# Simply open index.html in your browser — no build step required!
```

**That's it!** No npm, no webpack, no build tools. Just pure HTML, CSS, and JavaScript.

## 🌐 Deployment

### GitHub Pages (Recommended)

1. Fork this repository
2. Go to **Settings** → **Pages**
3. Set **Source** to `master` branch
4. Your site will be live at `https://YOUR-USERNAME.github.io/portfolio/`

### Other Hosting Options

Works on any static hosting service:
- **Netlify** — Drag & drop deployment
- **Vercel** — Git integration
- **Surge** — CLI deployment
- **Firebase Hosting** — Google's platform

## 🎨 Customization

### Colors

Edit the CSS variables in `styles.css`:

```css
:root {
  --primary: #00ff88;
  --secondary: #0099ff;
  --accent: #ff0080;
  --bg-dark: #0a0a0a;
}
```

### Content

Update your information in `index.html`:
- Personal info in the hero section
- Projects in the projects section
- Skills and experience in respective sections
- Contact details in the footer

### Animations

Adjust animation speeds in `styles.css` and `script.js` to match your preferences.
